# Roadmap and release gates

No stable release is declared by this setup. Complete and record these gates before a release:

- Verify reconnect and HDMI audio on J293.
- Qualify suspend/resume and an independent stock boot.
- Review shared m1n1 DTB recovery on a spare installation.
- Update the stable pin without losing stable fixes.

Each gate needs a reproducible test or a reviewable evidence record. GitHub issues track the work; the [GitHub Project](https://github.com/users/Connorbelez/projects/15) groups the backlog.
